- 列：被质检人 / 记录数 / 扣罚金额 / 一般问题 / 严重 / 严重需整改 / 讲解-确认完成情况。

### qc_records 关键字段真实值（后续开发直接复用，别再猜）
- `severity` 三档：**'一般'** / **'严重'** / **'严重需整改'**（一般提醒不扣钱，penalty_amount=0）
- `penalty_amount`：扣罚金额；`status === 'done'`：已讲解
- `staff`：被质检客服姓名；`shop`：店铺；`date`：日期
- `created_by`：**质检人手机号（不是姓名）**，须经 `qcReportPhoneMap`（phone→profile）反查姓名
- `qc_templates`：常用问题模板表，RLS FOR ALL true，6 条种子；**建表 SQL 杨茹仍未执行**，当前走内置兜底模板

### 实现（index.html，commit `a7f5ddd`）
- 新增常量 `QC_FIXED_INSPECTORS = ['小念','小暖','小雷']`
- `qcInspectorNameOf(r)`：created_by 手机号 → 质检员姓名
- `getQcInspectorList(data)`：当前登录者排最前 + 固定三位 + 数据里出现的其他人 → 保证四人恒定显示，无记录也出空表
- `groupQcByInspectorStaff(data)`：两级聚合（质检员 → 被质检人），统计 记录数 / 扣罚 / 三档严重度 / 已讲解
- `renderQcInspectorDetail()`：每人一个 `.qc-insp-group`，标题含姓名+总条数+总扣罚，末尾合计行
- 报告页新增区块「质检员明细（每人一表）」`#qc-report-by-inspector-detail`（样式内联在区块内）
- Excel 新增 sheet「按质检员明细」，8 列严格对齐她的模板
- 讲解进度格式定为 `已讲解/总数`（如 2/3）；想改百分比直接改这一处
