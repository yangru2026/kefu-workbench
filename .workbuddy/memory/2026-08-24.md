## 归纳：质检扣罚规则表（基于 qc_records 真实数据）
- **数据源**：Supabase `qc_records` 表，34 条记录（全部来自抖音4店），severity 三档：一般2 / 严重15 / 严重需整改17。
- **金额分布**：0元×2、3元×10、5元×6、10元×14、15元×1、20元×1。
- **归纳规则（类型 / 具体原因 / 扣罚金额）**：
  - 一般提醒（0元）：轻微话术/流程瑕疵，如重复短句回复、只回"好的"、先发有货未协商。
  - 严重问题-5元：机械复制重复话术、敷衍回复；该主动引导未引导（未问地址时效、未引导半年抛/39.9三副预定、未推荐合适花色）。
  - 严重问题-3元：信息单薄未讲卖点、答非所问、未挖掘需求、态度稍弱。
  - 严重需整改-3元：推荐不精准（未确认需求直接甩图/甩款）。
  - 严重需整改-10元：连续大段话术刷屏/信息过载、未挖掘需求直接丢款式、缺货未查补货群、未回复客户、直接"没有"结束、回复完不引导不跟进直接送客、冷漠机械无服务意识。
  - 严重需整改-15元：反复追问同一问题仍复制营销话术（如活动结束时间）。
  - 严重需整改-20元：严重机械重复回复，不尊重客户（多轮连续复制一模一样）。
- **结论**：扣罚由管理员按情节裁量，无绝对公式；金额梯度 0/3/5/10/15/20。所有案例均抖音4店，规则可推广但需结合各店实际。
- **注**：本次用 anon key 经 REST API 拉取，已删除本地 qc_data.json（含敏感数据）。
