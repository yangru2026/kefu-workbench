## 花色素材库分类管理功能
- **新建表 `pattern_categories`**：存储四种分类维度（brand/type/series/color），支持排序，UNIQUE(category_type, name) 约束
- **前端改造**：
  - `patternCategories` 全局变量 + `loadPatternCategories()` 从 Supabase 加载
  - `subscribePatternCategories()` 实时订阅变化
  - `getMergedCats()` 合并托管分类与数据驱动分类（去重、排序）
  - `renderPatternFilters()` 重写：品牌tab、抛型/系列/色系 flink 均显示管理按钮
  - 新增 CRUD 函数：startEditPatCat / confirmEditPatCat / cancelEditPatCat / deletePatCat / addPatCat
  - 编辑分类名称时级联更新 pattern_assets 表中对应字段（brand/type/series/color）
  - 删除品牌/抛型时检查是否有花色使用，有则阻止删除；删除系列/色系时清空关联花色的对应字段
  - 编辑器下拉框改为从托管分类读取（品牌、抛型、色系均动态获取）
- **CSS**：新增 .pcat-edit-btn / .pcat-del-btn / .pcat-add-mini / .pcat-inline-edit 样式
- **fallback**：表未创建时使用数据驱动分类，不显示管理按钮
- ⚠️ **需要用户操作**：在 Supabase SQL Editor 执行 `add_pattern_categories.sql` 建表并播种初始数据
- 已部署到 GitHub Pages
