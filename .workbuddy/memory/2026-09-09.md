## 性能优化：工作台加载超慢（用户截图反馈「加载超慢的」）
- 根因：①首页 ~1MB，其中 ~212KB 是**整段内联 supabase SDK**，无法单独缓存；②每次打开都向 supabase.co（Cloudflare 新加坡节点）重新拉全部表数据，杭州往返慢；③无顶层启动动画，下载解析期间白屏像卡死。
- 方案（茹姐选「核心提速 1+2+3」）：
  1. **删内联 SDK**：移除 `<script id="supabase-inline-lib">`，改由已有 `vendor/supabase.min.js`（本地优先 + 多 CDN 兜底 loader）加载 → 首页 1MB→812KB，SDK 单独可缓存（冒烟实测 vendor 加载 250ms 就绪）。
  2. **本地缓存静态数据**：新增 `kefuCacheGet/kefuCacheSet`（key=`kefu_cache_<table>`，版本号 `KEFU_CACHE_VER='v1'`）。5 个 load 函数（training_materials/categories/knowledge/scripts、pattern_assets）改「先秒显缓存→后台静默刷新→回写缓存」；gift.html 的 `loadGifts` 同样改造（key=`kefu_cache_gift_codes`）。首页打开先渲染缓存，体验秒开。
  3. **启动加载动画**：新增 `#boot-splash`（小布转圈 + 「正在加载工作台…首次加载稍慢，已为你缓存常用数据」），`initSupabase` 完成后 `hideBootSplash()`，外加 8s 兜底 + load 事件双保险，永不白屏卡死。
- 验证：node 内联脚本语法检查全过；puppeteer-core + Edge 无头（拦截 supabase 返回 mock，超时保护 evaluate）：首页 supabase 就绪、splash 显隐正常、无 pageerror、`kefu_cache_*` 5 个键全部写入；gift 页 `kefu_cache_gift_codes` 写入。switchPage 切页无冻结无报错。
- 提交：commit 待 push（本会话结束前）。注意：移除内联 SDK 后 `window.supabase` 初始化后会被覆盖为客户端实例（含 `.from`、无 `.createClient`），测试断言要用 `typeof window.supabase.from==='function'` 而非 `.createClient`。

## 赠品页编辑弹窗焦点切换仍闪退（第三轮修复，commit 7941db1）
- 现象：先改简称，再点商家编码输入框时仍会闪一下。
- 根因：`.modal-mask` 仍有 `overflow-y:auto`，输入框焦点切换时浏览器自动滚动**祖先遮罩层**，导致整个弹窗在 iframe 里跳动。
