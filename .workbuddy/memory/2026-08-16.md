## 质检工具：客服姓名 / 店铺 可管理（Supabase 驱动）
- 用户需求：客服姓名和所属店铺要能「管理员新增/删除」，录入时直接下拉勾选（不再手填/硬编码）。
- 实现（qc-v2.html）：
  - 新增 `qc_staffs` / `qc_shops` 两张表（SQL: `add_qc_staff_shop_tables.sql`，含 RLS：public 读、authenticated 写；店铺已 seed 11 个，客服由管理员自行添加）。
  - `inpStaff`(原 text) 与 `inpShop`(原硬编码 option) 改为动态 `<select>`，数据来自 `qc_staffs`/`qc_shops`（按 sort_order 排序）。
  - 新增管理弹窗 `ssMgrModal`（⚙️ 按钮在姓名/店铺标签旁打开），分「客服姓名 / 所属店铺」两个 tab，支持 新增 / ▲▼排序 / 🗑️删除（删除有 confirm 二次确认，仅移除选项、不影响历史记录）。
  - 核心函数：`loadStaffs` / `loadShops` / `refreshStaffShopSelects`（同时刷新新增表单 + 筛选下拉，筛选下拉合并历史记录值）/ `openSsMgr` / `addSs` / `deleteSs` / `moveSs`。
  - `editRecord` / `saveEdit` / `updateFilterOptions` / `prefillLast` 同步改为读表；`prefillLast` 用 `ensureSelectOption` 兼容历史值未入表的情况。
  - `init()` 新增调用 `loadStaffs()` + `loadShops()`。
- 测试：node 语法校验 0 错；puppeteer-core + Edge 无头冒烟（stub `var supabase=null;` 为内存假对象）全通过：select 渲染、管理员增删客服/店铺、tab 切换、下拉联动，0 个 JS 运行时错误。
