## Bug 修复：公告栏卡住"加载中..."（17:12）
- **问题原因**：`loadAnnouncements()` 请求 Supabase 失败时只 `console.error`，没有更新页面 DOM，导致一直显示"加载中..."
- **次要原因**：`loadConfig()` 的 catch 块里没有调用 `initSupabase()`，如果 `config.json` 加载失败，Supabase 永远不会初始化
- **修复内容**：
  1. `loadAnnouncements()` 增加 try-catch，出错时显示具体错误信息 + 重试按钮
  2. `loadConfig()` catch 块里也调用 `initSupabase()`，确保无论配置加载成败都会初始化 Supabase
  3. `initSupabase()` 增加 `window.supabase` 存在性检查，防止 CDN 未加载时报错

## Bug 修复：页面完全卡死，JS 语法错误（17:26）
- **问题原因**：Supabase CDN 库（`supabase.min.js`）内部用 `var supabase` 声明了全局变量，我们的代码又写了 `let supabase = null;`，同一全局作用域内重复声明导致 `SyntaxError`，整个脚本崩溃，所有函数（包括 `switchPage`）都没定义
- **修复内容**：将 `let supabase = null;` 改为 `supabase = null;`（去掉 let，复用 CDN 已声明的变量）
- 已部署到 GitHub Pages
