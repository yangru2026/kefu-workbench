## 分享页“一直加载”修复
- 现象：客服在微信打开一对一质检反馈链接，始终显示「⏳ 正在加载…」。
- 根因：中国大陆访问 Supabase / jsdelivr CDN 可能极慢或被拦截；原 `loadSupabase()` 无超时、无 fallback，请求 pending 时页面不会给出任何错误。
- 修复（`qc-share.html`）：
  - `loadSupabase()` 增加多 CDN fallback（jsdelivr / unpkg / bootcdn），10s 超时，逐个节点尝试。
  - 增加 `withTimeout()` 包装，所有 Supabase 查询（qc_shares、qc_records）加 15s 超时。
  - 加载中提示变为「正在连接服务…（尝试节点 x/3）」；失败时显示具体原因与解决建议（换 4G/5G、用浏览器打开）。
  - 错误提示区分：缺少 token、脚本加载失败、查询超时、链接无效。
- 新增 `fix_qc_share_public_rls.sql`：确保 `qc_shares` 和 `qc_records` 都允许 `anon` 角色读取（分享页客服未登录），并刷新 PostgREST schema cache。
- 语法校验 0 错。commit ab05f40 已 push。
- 用户需执行 `fix_qc_share_public_rls.sql`；如仍卡，建议客服换网络或用浏览器打开。
