### 从 Excel 批量导入店铺场景话术到售前话术板块
- **需求**：用户给 `抖音_弥生电子美瞳专卖店_店铺场景_2026-08-27.xlsx`（Downloads 目录），要求把场景话术放进售前话术板块并分类。
- **读取**：本地 xlsx 走 tencent-docs-routing → tencent-local-office-edit 打开失败（editor_sdk 异步流不驻留）、sheet-agent 子代理工具未连接；最终回退用 venv 的 openpyxl 直接解析（sheet=场景，7列：场景名称/策略名称/文本话术_1~5，127 行）。
- **映射规则**：每行=1 条 training_scripts 记录；5 列话术依次映射 标准/亲切/简短/专业/安抚；`<新消息分隔符>` 转换行；title=策略名称(去【】前缀)，通用策略用场景名；tags=[售前/售后/通用]；subcategory 按【售前】/【售后】标记+关键词分到 7 类（佩戴问题22/产品咨询26/订单物流25/售后处理44/价格优惠4/平台规则1/促单成交5）。
- **产出**：`add_scripts_from_excel.sql`（自包含：建表+RLS+updated_at 触发器+「售前话术」大类+7 小类+幂等 delete 本类+插入 127 条）。生成脚本 `outputs/gen_scripts_sql.py`。
- **校验**：128 个 jsonb 串 JSON 合法 0 非法；单引号转义正确。
- **交付**：用户只需在 Supabase SQL Editor 执行这一个文件即可（之前的 add_training_scripts.sql 不再需要单独执行，本文件已含建表；执行会清空本类旧示例换成 127 条真实话术）。
