## 排班表飞书同步后无颜色 (2026-08-11)

**问题**：从飞书同步排班后，单元格只剩文字（早/中/晚/休/调），背景颜色全部丢失。

**根因**：
- 飞书表格里存的班次文字是**单字**（"早"、"中"、"晚"、"休"、"调"）
- 前端 `renderSchedule` 颜色 CSS class 判断用的是**全称**（`shift.includes('早班')`、`shift === '休息'` 等）
- 单字匹配不上 → 拿不到 CSS class → 没颜色

**修复**：
- 修改 `index.html` 第 5371-5376 行（`renderSchedule`）和第 5531-5536 行（编辑后刷新）班次判断
- 现在两种格式都支持：
  - 单字：'早' / '中' / '晚' / '休' / '调' / '班'
  - 全称：'早班' / '中班' / '晚班' / '休息' / '调休' / '加班'

## 客服申请审批系统 (2026-08-11)

**功能**：客服可提交换班/加班/调休申请，管理员审批通过后自动联动更新排班表/加班时长/调休时长，无需多处修改。

**数据库**：
- 新建 `cs_requests` 表（`create_cs_requests_table.sql`）
- 字段：id, type(shift_swap/overtime/compensatory_leave), requester_id, requester_name, status(pending/approved/rejected), target_date, shift_from, shift_to, hours, reason, reviewer_id, reviewer_name, reviewed_at, created_at
- RLS：所有登录用户可查看和新增，仅管理员可更新（审批）

**前端**（`index.html` + `app.js`）：
- 侧边栏新增「📝 申请审批」入口（排班表下方），管理员看到待审批数量 badge
- 申请表单：3 种类型 tab 切换
  - 换班：选日期→自动获取当前班次→选目标班次→填原因
  - 加班：选日期→填时长→填原因
  - 调休：选日期→填时长（显示可调休余额）→填原因
- 申请列表：待审批/已通过/已拒绝/全部 tab 筛选，管理员看全部，普通客服只看自己
- 审批：管理员点「通过」/「拒绝」，通过后自动联动

**自动联动逻辑**（`app.js`）：
- `applyShiftSwap`：换班通过 → 查 schedule_data 获取该月该人排班 → 修改对应日期班次 → upsert 回数据库 → 更新内存缓存 → 如当前在排班页则重新渲染
- `applyOvertime`：加班通过 → insert overtime_records（profile_id, date, hours, note="审批通过: "+reason）→ 更新本地缓存
- `applyCompensatoryLeave`：调休通过 → insert compensatory_leave_records → 更新本地缓存

**Realtime**：`subscribeRequests()` 监听 cs_requests 表变更，自动刷新申请列表
