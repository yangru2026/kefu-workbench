- 需求：一般提醒不扣钱；严重问题 / 严重需整改由管理员自定义填写扣罚金额。
- DB：`add_penalty_amount.sql` 给 `qc_records` 加 `penalty_amount NUMERIC DEFAULT 0`（用户需在 Supabase SQL Editor 执行一次）。
- 三页面同步改造：qc-v2.html（工作台内置 / iframe）、qc.html（独立页）、qc-share.html（客服只读查看）。
- 逻辑：录入/编辑表单在 severity 组后加「扣罚金额(元)」数字框；选一般提醒时 disabled 并清空，选其他类型时启用。addRecord/saveEdit 读值写入 penaltyAmount/penalty_amount，syncRecord 入库 penalty_amount。
- 展示：列表卡片 severity 标签旁显示「💰扣 ¥X」红标；客服只读页同样展示；单人分析报告(renderStaffAnalysis/renderAnalysisSheet)加「扣罚汇总」段（总额+条数+按月）；全部汇总 KPI 加「扣罚总额」；CSV 导出加「扣罚金额」列。

## 修复质检页面文字粘贴失效
- 现象：聊天记录/客服回复/知识点配图区域内的 textarea 无法粘贴从其他地方复制的文字。
- 根因：`setupZone` 中对 paste 事件统一 `e.preventDefault()`，随后用自定义代码把文字插入 textarea，但变量 `end` 未定义（应为 `ta.selectionEnd`），导致纯文字粘贴报错失效。
- 修复（qc-v2.html + qc.html）：改为只在检测到剪贴板里有图片时才 `preventDefault()` 并处理图片；纯文字粘贴不拦截，交给浏览器默认行为。
- 提交：`fee84ca`，已推送到 main。
