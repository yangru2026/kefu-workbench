# 2026-08-20

## 修复：新增花色 lightbox 大图加载失败
- **现象**：用户截图显示新增花色点击后 lightbox 提示"图片加载失败，可点击重试"。
- **根因**：新花色图片从飞书附件同步到 Supabase Storage `pattern-images` bucket，单张 1MB+；当前环境访问 supabase.co 下载需 6.5s，前端 lightbox 5s 超时即判定失败。
- **修复**（`index.html`）：
  1. `loadLightboxHd` 超时延长至 20s（仅当候选 URL 包含 supabase.co 时）；超时后显示"图片较大，加载中…"，不再直接报失败。
  2. 候选 URL 去重逻辑修复，避免 supabase URL 经 `toDirectUrl` 后重复。
  3. `showLightboxImage`：当 thumb/hd 为同一源时（Supabase 无中图）不再加 `thumb-placeholder` 模糊，避免 1.3MB 原图被 CSS 模糊显示。
- **验证**：inline script 语法检查 0 错误；仍需用户线上验证。
- **后续建议**：长期应对 Supabase Storage 大图进行压缩/生成中图（Edge Function 同步时处理），否则国内客服加载大图仍会较慢。
