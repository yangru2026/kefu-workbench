## 修复质检页面文字粘贴失效
- 现象：聊天记录/客服回复/知识点配图区域内的 textarea 无法粘贴从其他地方复制的文字。
- 根因：`setupZone` 中对 paste 事件统一 `e.preventDefault()`，随后用自定义代码把文字插入 textarea，但变量 `end` 未定义（应为 `ta.selectionEnd`），导致纯文字粘贴报错失效。
- 修复（qc-v2.html + qc.html）：改为只在检测到剪贴板里有图片时才 `preventDefault()` 并处理图片；纯文字粘贴不拦截，交给浏览器默认行为。
- 提交：`fee84ca`，已推送到 main。

## 修复讲解模式编辑弹窗与图片问题
- 现象：点击讲解模式内「编辑」按钮无反应；用户担心录入时贴的截图丢失。
- 根因1：editModal(430行)在 DOM 中位于 coachModal(437行)之前，二者 z-index 同为1000，按 CSS 后定义盖上的规则，编辑弹窗被讲解弹窗遮挡 → 点编辑看似没反应。
- 根因2：saveEdit→syncRecord 用 `record.sceneImages = await uploadPendingImages('scene')` 覆盖，而编辑弹窗无贴图区，pendingImages 为空，导致原图被清空（编辑一次图片就没）。
- 修复（qc-v2.html + qc.html）：① CSS 加 `#editModal{z-index:1100}`；② syncRecord 改 `[].concat(record.keepSceneImages||[], await uploadPendingImages(...))`，saveEdit 前把原图存入 keep* 列表，保留原图仅追加新图；③ 编辑弹窗新增「已有截图」展示区（renderEditImages 异步渲染 + removeEditImage 删除）。
- 验证：node new Function 语法校验两文件 OK；无头浏览器实测 editAboveCoach=true、编辑弹窗 editImgHasImg=true。
- 说明：用户反馈「讲解模式 #1#2 没截图」经核查数据库 scene_images 有值、图片 URL 返回 200、渲染函数实测能出图，故为页面未强刷到最新版或列表页异步加载慢所致；部署后请 Ctrl+Shift+R 强刷确认。
- 提交：`1bcc371`，已推送到 main。
