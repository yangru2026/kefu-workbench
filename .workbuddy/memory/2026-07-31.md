## 花色素材分类管理 — 修复色系右键无效 + 兼容数据驱动分类

### 问题根因
- 色系分类在 `pattern_categories` 表中没有记录（SQL 初始种子用的是"紫色系/棕色系/蓝色系"等带"系"的名称，而实际花色数据中是"紫色/棕色/蓝色"），导致 `getMergedCats` 将所有色系都标记为 `isManaged: false`，`oncontextmenu` 属性没有被添加，右键菜单出不

### 修复
1. **抛型/系列/色系强制支持右键**：去掉 `isManaged` 判断，管理员身份下所有分类标签都添加 `oncontextmenu`
2. **删除兼容**：即使 `patternCategories` 里没有该分类记录，也允许删除——直接清空关联花色的对应字段并刷新即可
3. **编辑兼容**：数据驱动分类改名时，自动插入一条新的托管分类记录到 database，使其变为可管理的分类
4. 已部署到 GitHub Pages

## 修复质检工具缓存与 supabase 重复声明

### 问题根因
- 浏览器顽固缓存 index.html 和 qc.html（GitHub Pages CDN）
- supabase-js@2 UMD 构建在全局声明 `var supabase`，与 qc-v2.html 中的 `let supabase` 在同一作用域冲突，抛出 SyntaxError

### 修复
- qc.html 复制为 qc-v2.html 绕过缓存
- iframe onload 从 HTML 内联移除，改为 DOMContentLoaded 动态绑定
- `let supabase` → `var supabase = window.__qcSupabase || supabase.createClient(...)`，利用 var 允许重复声明
- 添加 isAdminUser 函数，updateStats 增加空值保护
- 已推送部署
